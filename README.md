# ListasDeFazeres
faz uma lista pro seu usuario determinadas tarefas de acumulo 
 # ✅ To DE List

Uma aplicação simples e funcional de lista de tarefas (To-Do List) desenvolvida com **Python** e **Kivy**, com armazenamento local utilizando **JSON**.

---

## 📌 Funcionalidades

- ➕ Adicionar novas tarefas  
- ✅ Marcar tarefas como concluídas  
- ❌ Excluir tarefas  
- 💾 Salvamento automático dos dados em arquivo `.json`  
- 🔁 Carregamento das tarefas na inicialização  

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição |
|------------|-----------|
| Python     | Linguagem principal |
| Kivy       | Framework para interface gráfica |
| JSON       | Formato de armazenamento de dados |
